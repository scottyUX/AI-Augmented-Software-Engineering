# Week 5 Submission: Mohamad Abdullah Abd
**Project repository:** https://github.com/mohamad-abdullah-710/week5-mcp
This public repository contains my Week 5 Data Explorer MCP server with two tools, `search_countries` and `get_country_details`, both hardened against bad input and API failures. The starter's REST Countries v3.1 API is deprecated, so the server was updated to v5 (API key read from an environment variable) and `mcp` is pinned below 2.
`README.md` has the setup, Claude Code registration and tool reference; `writeup.md` and `transcript.txt` show Claude Code calling both tools, the error handling, and what I learned.
