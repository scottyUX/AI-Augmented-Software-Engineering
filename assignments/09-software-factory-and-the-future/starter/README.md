# Starter — Event RSVP (app spec)

There is no code to run here — this week you **generate** the app.

## How to use
1. Open [`PROMPT.md`](PROMPT.md) and copy its contents.
2. Paste it into [bolt.new](https://bolt.new/) as your starting prompt.
3. Iterate until the app meets the scope in the prompt.
4. Export the generated code into your repo under `event-rsvp/`, then evaluate and fix
   at least two things the generator got wrong.

## Files
- `PROMPT.md` — the ready-to-paste Event RSVP app specification
